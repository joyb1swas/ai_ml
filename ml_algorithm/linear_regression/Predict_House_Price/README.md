# House Price Prediction

A machine learning practice project using **Linear Regression** to predict house prices with Scikit-learn.

## Files

- [`house_price_prediction.ipynb`](house_price_prediction.ipynb) — Builds and trains the linear regression model.
- [`house_price_joblib.ipynb`](house_price_joblib.ipynb) — Practices saving and loading the trained model using Joblib.
- [`house_price_model.pkl`](house_price_model.pkl) — Saved model file for reuse without retraining.

## Tools

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Joblib
